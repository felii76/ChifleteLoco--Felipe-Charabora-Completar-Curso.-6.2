# Chiflete Loco

Sistema web de gestión desarrollado para la empresa Chiflete Loco.

## Descripción

El sistema permite administrar diferentes procesos de la empresa, principalmente clientes, productos, pedidos, facturación y control de stock.

## Funcionalidades

- Gestión de clientes.
- Gestión de productos.
- Registro y modificación de pedidos.
- Detalle de pedidos.
- Cambio de estado de los pedidos.
- Facturación.
- Envío simulado de facturas.
- Control de stock de productos terminados.
- Control de stock de materias primas.
- Registro de movimientos de stock.
- Informes.
- Generación de informes en PDF.

## Tecnologías utilizadas

- PHP
- MySQL
- HTML
- XAMPP
- FPDF
- Visual Studio Code

## Base de datos

La base de datos utilizada por el sistema se encuentra en:

`database/chiflete_loco.sql`

## Instalación

1. Instalar XAMPP.
2. Copiar el proyecto dentro de `htdocs`.
3. Iniciar Apache y MySQL.
4. Crear la base de datos `chiflete_loco`.
5. Importar `database/chiflete_loco.sql`.
6. Abrir:

`http://localhost/chiflete-loco/`
